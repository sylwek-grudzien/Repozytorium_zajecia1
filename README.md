# Repozytorium_zajecia1
Repozytorium testowe 

Repozytorium ćwiczeniowe utworzone podczas zajęć z Git, GitHub i VS Code. Służy do przećwiczenia dodawania plików, klonowania repozytorium, zapisywania zmian w historii Git oraz wysyłania ich na GitHub.

## Zawartość

- `main.py` — przykładowy skrypt Python do ćwiczenia pracy ze zmianami w repozytorium.
- `T01_audyt_danych_STUDENT (1).ipynb` — notebook z ćwiczeniem dotyczącym audytu danych.
- `README.md` — opis repozytorium i instrukcja uruchomienia plików.

## Wymagania

- Python 3 — do uruchomienia `main.py`.
- Git — do sklonowania repozytorium.
- Środowisko obsługujące Jupyter Notebook, np. VS Code z rozszerzeniami Python i Jupyter — do pracy z plikiem `.ipynb`.

Notebook może wymagać dodatkowych bibliotek wskazanych w instrukcjach `import` w jego komórkach.
## Uruchomienie skryptu Python

Będąc w folderze repozytorium, uruchom w terminalu:

```bash
python main.py
```

Na niektórych komputerach zamiast `python` należy użyć `py` lub `python3`. Wynik działania skryptu zależy od jego aktualnej zawartości.

## Praca z notebookiem

1. Otwórz `T01_audyt_danych_STUDENT (1).ipynb` w VS Code.
2. Wybierz środowisko Pythona (*kernel*) w prawym górnym rogu notebooka.
3. Przeczytaj instrukcje i uruchamiaj komórki po kolei.
4. Zapisz wykonane zmiany przed utworzeniem commita.
